# 🧑‍💻 Dzaky Khairullah PN — Portfolio Website

Personal portfolio website built with HTML and CSS as part of my web development learning journey at Dicoding Indonesia.

🔗 **Live Demo:** [portofolioikyydzaky12.netlify.app](https://portofolioikyydzaky12.netlify.app)

---

## 📋 About

This project is a personal portfolio website that showcases my profile, skills, and contact information. Built from scratch using semantic HTML and CSS Flexbox layout.

---

## ✨ Features

- Responsive layout using **CSS Flexbox**
- **Dark / Light mode** toggle
- Semantic HTML structure (`header`, `nav`, `main`, `article`, `aside`, `footer`, `section`)
- Smooth scroll & fade-in animations
- Mobile friendly design

---

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, CSS Variables, Media Query)
- JavaScript (DOM manipulation)
- [Google Fonts](https://fonts.google.com) — Syne & DM Sans
- [Font Awesome](https://fontawesome.com) — Icons
